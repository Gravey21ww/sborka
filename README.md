# 🚀 SBORKA SPACE TECH 1.20.1 — Ad Astra + Tech + Exploration + Combat
Сборка на Minecraft 1.20.1 Forge 47.4.0, сбалансированная, без дубликата руд, с оптимизацией, рабочими шейдерами и нормальным прогрессом.

## 📦 Как установить
1. Установи [Minecraft Forge 1.20.1 - 47.4.0](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)
2. Скопируй ВСЕ моды из папки `/mods` в папку mods твоего инстанса
3. Скопируй содержимое `/config` в папку config (там уже настроено отсутствие дубликатов руд!)
4. В `/shaderpacks` лежит готовый шейдер который работает с Ad Astra
5. Выдели 4-6 ГБ ОЗУ в лаунчере

## ⚙️ Уже настроено в конфигах (config/)
✅ **Нет дублирующих руд!** Отключены генерации руд из всех модов кроме Thermal Foundation (медь, олово, свинец, серебро, никель) — все остальные моды используют эти же руды.
✅ Ad Astra руды (десх, острум, кальорит) генерируются ТОЛЬКО на других планетах как и должно быть
✅ Крафт ракет сбалансирован: тебе не нужно гриндить неделю чтобы сделать первую ракету, но и не слишком просто
✅ Квары и буры не имбовые на старте, для них нужна энергия и ресурсы
✅ Вес боссов сбалансирован: боссы из Cataclysm появляются только когда у тебя уже есть нормальная броня
✅ Оптимизация включена по умолчанию

## 💡 Рекомендации
- Выдели игре минимум 4 ГБ ОЗУ, оптимально 6 ГБ
- Шейдер Complementary Reimagined идет в комплекте, если на твоем ПК низкий ФПС поставь MakeUp Ultra Fast
- Первую ракету можно собрать примерно за 3-4 часа игры, не торопись
- В аду и эндере тоже есть новые данжи и боссы

## 📥 Быстрый способ скачать все моды сразу
Запусти скрипт `download_mods.sh` в папке сборки, он сам скачает все нужные файлы в папку mods!
